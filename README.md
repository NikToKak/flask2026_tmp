ТЕХНИЧЕСКОЕ ЗАДАНИЕ
«Транслятор ограниченного подмножества Python в C с использованием AST дерева»

Версия: 1.0
Дата: 2026-06-15

1. Цель:
Разработать программу (транслятор), которая преобразует исходный код на языке Python (ограниченное подмножество) в эквивалентный код на языке C.
Транслятор должен автоматически генерировать C-код, который может быть скомпилирован любым стандартным компилятором (gcc, clang) при условии подключения пользователем необходимых заголовочных файлов (stdio.h, stdlib.h, string.h, math.h).

Назначение:
- Обучение принципам трансляции и работы с абстрактными синтаксическими деревьями (AST).
- Быстрое прототипирование C-программ из Python-скриптов.
- Использование в качестве основы для более мощных трансляторов.

2. Требования к входным данным
Транслятор принимает на вход текст программы на Python, удовлетворяющий следующим ограничениям:

- Программа может быть представлена либо одной функцией def, либо последовательностью инструкций (скрипт). Во втором случае транслятор автоматически оборачивает код в int main().
- Функция (если задана) может иметь один аргумент (массив целых чисел int *arr) или два аргумента (массив и его длина int len). Возвращаемый тип — int.
- Поддерживаемые типы данных: int, float (в C double), строки (char*).
- Поддерживаемые литералы: целые, вещественные, строковые (в двойных кавычках).
- Поддерживаемые операторы:
  Арифметические: +, -, *, /, // (целочисленное деление), %, ** (возведение в степень).
  Сравнения: ==, !=, <, >, <=, >=.
  Логические: and, or, not.
  Присваивания: =, +=, -=, *=, /=, //=, %=.
- Управляющие конструкции: if/elif/else, while, for i in range(start, stop, step), for x in arr (только для массива-аргумента), break, continue.
- Ввод/вывод: print(expr, ...), input() (строковый), int(input()) (числовой).
- Массивы (списки): статические одномерные и прямоугольные двумерные, заданные литералами [1,2,3], [[1,2],[3,4]]; динамические через [0]*n (только с нулевым заполнением). Доступ по индексу arr[i], arr[i][j].
- Комментарии # ... (игнорируются).

2.1. Ограничения на входной код. Не допускается
- Множественное присваивание (a, b = 1, 2).
- Методы списков (.append(), .pop(), .insert() и т.д.).
- Срезы (arr[1:3], s[2:]).
- Индексация строк (s[0] – не гарантируется корректная работа).
- Преобразования типов, кроме int(input()). Функции str(), int() (от констант или переменных) не поддерживаются.
- set, dict, tuple (любые коллекции, кроме однородных списков).
- Глобальные переменные вне функции.
- Импорты (import, from).
- Классы, исключения, генераторы, лямбды, декораторы и т.п.
- Методы строк (.split(), .join() и т.д.).
- Форматированные строки (f-строки, .format).

3. Требования к выходным данным
На выходе транслятор выдаёт текст программы на языке C, который:

- Не содержит #include (пользователь добавляет их самостоятельно: stdio.h, stdlib.h, string.h, math.h по необходимости).
- Для динамических массивов и строк генерирует вызовы malloc() (пользователь при необходимости добавляет free()).
- Для возведения в степень генерирует вызов pow().
- Для строковой конкатенации генерирует malloc, strcpy, strcat.
- Для строковых сравнений использует strcmp().
- Для print() генерирует вызов printf() с автоподбором формата (%d, %f, %s).
- Для int(input()) генерирует scanf("%d", &var).
- Для обычного input() генерирует fgets(var, 256, stdin) и удаляет символ новой строки.
- Для циклов for x in arr использует переменную len (параметр функции) для ограничения итераций.

4. Функциональные требования
  1. Разбор исходного кода с помощью модуля ast (Python).
  2. Сбор всех используемых переменных в функции/скрипте для их объявления в начале блока.
  3. Вывод типов на основе первых присваиваний (с апгрейдом int -> double при необходимости).
  4. Генерация C-кода согласно описанным правилам.
  5. Автоматическая обёртка скрипта (без функции) в int main().
  6. Обработка ошибок при неподдерживаемых конструкциях (вывод исключения с сообщением).

5. Нефункциональные требования
- Не использует внешних библиотек, кроме стандартного модуля ast.
- Названия методов и переменных — осмысленные.

6. Примечания
ВАЖНО!
- Транслятор НЕ генерирует освобождение памяти (free). Это остаётся на усмотрение пользователя.
- В коде C не используются динамические структуры данных, кроме malloc для массивов и строк.
- Транслятор предполагает, что входной код синтаксически верен (не проверяет синтаксис Python – это делает ast.parse).
- На данный момент выходной С код считать НЕрабочим, доработка кода до рабочего состояния сотается на пользователе
